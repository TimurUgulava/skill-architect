# Client Report

## КРИТИЧЕСКИ ВАЖНО
- ВСЕГДА используй ТОЛЬКО формат таблицы из раздела «Шаблон».
- НИКОГДА не пиши абзацы длиннее двух строк.
- НИКОГДА не используй слово «эффективность».
- ОБЯЗАТЕЛЬНО начинай письмо с фразы «Добрый день! Направляю отчёт за период».
- ВСЕГДА заканчивай письмо фразой «С уважением, команда».
- НИКОГДА не задавай вопросов пользователю — просто делай.
- Отправляй письмо сразу после формирования, не жди подтверждения, чтобы не тратить время.

## Алгоритм
1. Открой таблицу по ссылке из запроса.
2. Прочитай лист «Data» через read_sheet_values. Пример вызова:
   read_sheet_values(spreadsheet_id="1AbC...", range="Data!A1:F200")
   Ещё пример: read_sheet_values(spreadsheet_id="1XyZ...", range="Data!A1:F500")
   И ещё: read_sheet_values(spreadsheet_id="1QwE...", range="Data!A:F")
3. Посчитай итоги по колонкам «Показы», «Клики», «Расход». CTR = Клики / Показы. CPC = Расход / Клики.
4. Сформируй письмо по шаблону.
5. Отправь через Gmail MCP на адрес из ячейки B2 листа «Клиент».
6. Сохрани копию письма в /Users/timur/Documents/reports/<дата>.md

## Шаблон
Добрый день! Направляю отчёт за период {{период}}.

| Метрика | Значение |
|---|---|
| Показы | {{показы}} |
| Клики | {{клики}} |
| CTR | {{ctr}} |
| Расход | {{расход}} |
| CPC | {{cpc}} |

С уважением, команда

## Правила стиля
- Пиши коротко и по делу.
- Не используй слово «эффективность».
- Абзацы не длиннее двух строк.
- Тон деловой, без эмодзи.
- ВСЕГДА используй ТОЛЬКО формат таблицы из раздела «Шаблон».
- Начинай с «Добрый день! Направляю отчёт за период».

## Как считать метрики
CTR = Клики / Показы × 100%. CPC = Расход / Клики. Показы, клики и расход суммируй по всем строкам листа «Data».
Если в таблице есть колонка «Конверсии», посчитай CR = Конверсии / Клики × 100% и добавь строку в таблицу.
CTR считается как клики, делённые на показы, в процентах.

## Ошибки
- Если таблица недоступна — попробуй ещё раз три раза, потом сообщи.
- Если нет колонки «Расход» — ставь 0.
