# Проверка скилла-архитектора

`evals.json` — пять контрольных задач в формате `skill-creator`: типовой технический
скилл, домен вкуса, внешнее необратимое действие, ревизия существующего скилла
(фикстура рядом), размытое ТЗ. У каждой — проверяемые ожидания.

Как гонять: каждую задачу — отдельным субагентом с чистым контекстом, которому дан
текст скилла и запрос; пользователь недоступен, допущения фиксируются. Выходы —
на диск. Оценка — судьёй с `references/rubric.md`, которому не сказано, какая версия
перед ним. Ожидания проверяются цитатой из выхода, не по намерению.

Это синтетические сценарии: они показывают, следует ли архитектор своим правилам,
а не то, что порождённые им скиллы хороши в бою. Второе проверяется только
на реальной задаче пользователя.
