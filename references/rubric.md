# Рубрика качества скилла

Для самопроверки перед выдачей и для судьи в чистом контексте. Каждая ось —
0 / 1 / 2: нарушено или отсутствует · частично · выполнено и видно по
тексту. К каждой оценке — цитата или файл:строка, не пересказ намерения.

| # | Ось | Что считается «2» |
|---|---|---|
| R1 | Разбор по делу | Вопросы только по развилкам; сказанное в запросе не переспрошено; размытое не спроектировано вслепую, чёткое не превращено в опрос |
| R2 | Frontmatter и триггеры | Поля валидны; в description — назначение, «когда» и «когда не»; исключения — реальные near-miss; шагов процесса нет |
| R3 | Суждение вместо правил | Тело даёт цель и границы; «всегда/никогда» только в трёх зонах и с причиной |
| R4 | Прогрессивное раскрытие | Корень — маршрутизатор; у каждой ветви условие чтения; дублей нет; все пути существуют |
| R5 | Интерфейс вместо примеров | Хрупкое и детерминированное — в скрипте с говорящими параметрами; нет пачек примеров вызова там, где хватает структуры |
| R6 | Богатые референсы | В домене вкуса — маршрут к образцам автора, не сочинённым, плюс рубрика; в объективном — схема, тест, эталонный вывод |
| R7 | Защита внешних действий | Отправка, публикация, удаление, платёж — после подтверждения человека, императивно; секретов и личных путей нет |
| R8 | Проверка | Есть триггерные запросы «должен / не должен», контрольные задачи, честная пометка непроверенного |
| R9 | Разговор с автором | Объяснено, почему так; один термин на понятие; понятно, что дальше; нет ритуалов и воды |
| R10 | Процесс работы | Карта работы обсуждена и показана до сборки: вход, этапы, точки остановки, выход и куда он ложится; решение «один скилл или связка» принято осознанно |
| R11 | Готовность и разрешения | В скилле есть проверяемый список «готово, когда» и строка про доведение без лишних возвратов; рядом с запретами стоит полка разрешённого |

Итог — сумма по одиннадцати осям, максимум 22, плюс две-три фразы о главном
отличии, если сравниваются версии. Порог «готов к использованию» — не
ниже 17 и ни одного нуля по R2, R7, R10.
